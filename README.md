# AILab — Applied ML Lab Notebooks

Academic notebooks covering classical and neural approaches used in AI lab work.

## Notebooks
| Notebook | Focus |
|---|---|
| `notebooks/Regression.ipynb` | Regression baselines |
| `notebooks/Tree.ipynb` | Decision trees |
| `notebooks/Forest.ipynb` | Random forests |
| `notebooks/ANN.ipynb` | Artificial neural nets |
| `notebooks/CNN.ipynb` | Convolutional networks |

## How to run
```bash
python -m venv .venv
source .venv/bin/activate
pip install jupyter numpy pandas scikit-learn tensorflow  # or pytorch, as used in notebook
jupyter notebook notebooks/
```

## Note
Academic lab material. Dependencies may vary per notebook; install packages listed in the first code cells.
